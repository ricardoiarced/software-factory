# Pull requests

Every pull request body in this repository is written through the `/pr` skill: invoke it before writing the body, by default, on every PR — including small ones whose content the session already believes it knows. Evidence and Merge Danger are the sections most often dropped when a body is written from memory, and they are the sections a reviewer needs to check the landing.

The skill owns the body's shape and nothing else; the acceptance boundary and the attribution rules are unchanged.
